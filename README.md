# Description:
A virtual dragon flies around the user. It will turn and follow the user as they move away from it, with a natural state where it circles the user, flying up or down at its own will.
The dragon will interact with objects, being drawn to certain items while avoiding others. 
The project is compatible with windows PC and Android mobile devices. The control scheme adapts to the platform used.

# Instructions:

Run the program on either a mobile device or pc, and watch the dragon fly around and feast on sheep that appear while roaring

# How it works:

The dragon uses boid seek behaviours to find its target locations. It will fly towards any sheep that appear and destroy them upon reaching them with its head. If it can't find a sheep, it will instead roam aimlessly in the sky around the user, following a target that randomly changes its location every few seconds.
