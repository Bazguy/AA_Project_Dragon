AA Project Proposal

Description:
A virtual dragon flies around the user. It will turn and follow the user as they move away from it, with a natural state where it circles the user, flying up or down at its own will.
Various buttons on the screen will spawn different objects that the dragon will interact with, being drawn to certain items while avoiding others. 
This project will be a mobile AR app built in Godot 4.6. It will use steering behaviours, procedural animations for the dragon's tail and wings, finite state machine architecture for decision making, and MobileVRInterface for the XR implementation.

I will be undertaking this project by myself.
